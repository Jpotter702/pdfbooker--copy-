### Documentation for Post-Crawl Results Dialog

**Post-Crawl Results Dialog Documentation**

We've implemented the Post-Crawl Results Dialog, allowing users to visualize the site structure and select pages for their PDF book. The implementation includes:

1.  **Site Structure Visualization**:

-   Hierarchical display of crawled pages
-   Visual indicators for parent-child relationships
-   Expandable/collapsible tree view of website structure
-   URL and title information for each page

2.  **Page Selection Interface**:

-   Checkboxes for including/excluding specific pages
-   Batch selection of pages by branch
-   Visual feedback for selected/unselected states
-   Counter showing total pages and selected pages

3.  **Page Arrangement**:

-   Drag-and-drop interface for ordering selected pages
-   Visual indicators for page order
-   Smooth animations during reordering
-   Easy-to-use visual interface

4.  **Page Preview**:

-   Preview panel showing page content (placeholder for now)
-   Link to view original page
-   Visual separation between selection and preview

5.  **User Experience Features**:

-   Tab-based navigation between structure and arrangement views
-   Clear instructions for each step
-   Real-time feedback on selections
-   Loading indicators during crawling

6.  **Validation**:

-   Warning when no pages are selected
-   Disabling of creation button until at least one page is selected
-   Status indicators for crawling progress
